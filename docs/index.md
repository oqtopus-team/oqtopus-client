# oqtopus-client

Python client library for the OQTOPUS Cloud User API.

This site collects the practical guides plus two kinds of API reference for
`oqtopus-client`: the higher-level SDK docs and the lower-level OpenAPI-generated
reference. Use it when you want installation and configuration steps, usage
examples, or detailed type and endpoint bindings.

## Start Here

- [Getting Started](usage/getting_started.md): installation, configuration, first job,
  and result handling.
- [Examples](usage/examples.md): sample scripts and pointers to the GitHub
  `examples/` directory.
- [API Reference](reference/index.md): both the SDK reference and the generated
  OpenAPI reference.
- [Developer Guidelines](developer_guidelines/development_flow.md): development
  flow, setup, and contribution guidance.
